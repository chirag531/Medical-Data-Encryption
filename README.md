# Medical Data Encryption (MDE)

## Overview
Medical Data Encryption (MDE) is a cybersecurity-based application designed to protect sensitive healthcare information through secure encryption techniques. The project ensures patient records remain confidential, secure, and accessible only to authorized users.

## Features
- Secure medical data encryption and decryption
- Protection against unauthorized access
- User authentication and access control
- Data confidentiality and integrity
- Simple and user-friendly interface

## Technologies Used
- Java
- HTML
- CSS
- JavaScript
- MySQL
- Cybersecurity Concepts

## Project Objectives
- Safeguard patient medical records
- Enhance healthcare data privacy
- Prevent data breaches and cyber threats
- Ensure secure storage and transmission of medical information

## System Modules
1. User Registration & Login
2. Medical Record Management
3. Data Encryption
4. Data Decryption
5. Secure Database Storage
